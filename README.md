# UserTrace Analytics

UserTrace Analytics is a web-based dashboard for tracking user interactions and usability data.

## Features

- Track total clicks
- Monitor button click counts
- Track scroll depth
- Display click heatmap
- View user activity logs
- Export interaction data as JSON

## Technologies

- HTML
- CSS
- JavaScript
- Google Colab
- Jupyter Notebook

## Project Purpose

This project demonstrates how user interactions can be captured and analyzed to provide simple usability insights.
